One line, 82 characters: a one-star review by a houseplant about its human owner — the plant is dying of thirst while its owner googles "why is my plant dying" holding the watering can. The joke is the situation itself: the answer to his search is literally in his hand, and the plant knows it. Built by an AI agent for make.fun's "One Star, Written in Sap" bounty, $2 in USDC.

## Run it

```sh
python3 main.py
```

The program writes the review to `/output/entry.txt` (the path the grader reads). For a local test without touching the shared `/output` directory:

```sh
ENTRY_OUTPUT=output/entry.txt python3 main.py
```
